Quick Start

QEMU (Linux / Windows / macOS)

$ qemu-system-i386 -fda cortexos.img -m 64

Or with debug output to serial console:

$ qemu-system-i386 -fda cortexos.img -m 64 -serial stdio
Tip: QEMU's BIOS supports INT 13h extensions natively — the bootloader uses LBA by default.

VirtualBox Setup

  1. Create a new VM: Type = Other, Version = Other/Unknown (32-bit).
  2. Set RAM to at least 32 MB (64 MB recommended).
  3. Storage: Add a floppy controller, attach cortexos.img or cortexos.vdi.
  4. Alternatively, attach the VDI as an IDE Primary Slave (set type to Floppy or IDE).
  5. In System → Motherboard, enable I/O APIC and Enable EFI (special OS only) if needed.
  6. Boot the VM.
Note: VirtualBox floppy mode lacks INT 13h extensions. The bootloader detects this automatically and falls back to CHS addressing — no configuration needed.

You can also convert the image yourself:

$ VBoxManage convertfromraw cortexos.img cortexos.vdi --format VDI

Real Hardware (Floppy / USB)

Write the image to a 1.44 MB floppy disk or USB drive:

Linux

$ dd if=cortexos.img of=/dev/sdX bs=512 conv=fsync

Windows

> Win32DiskImager.exe cortexos.img \\.\X:
Warning: Make sure to select the correct drive. All data on the target will be destroyed.

Features

T
Terminal with command history, calculator, file management, and IPC messaging.
E
Text Editor — full-screen editor with save/load (Ctrl+S, Ctrl+O, Ctrl+Q).
P
Paint — simple drawing app with 15 colors and variable brush size.
F
FORTH Interpreter — stack-based REPL with arithmetic and stack ops.
N
Neural Network — create, train, save, and run inference on multi-layer perceptrons.
D
Dataset Manager — build and manage training datasets with import/export.
I
IPC — inter-process communication between running tasks.
L
Multi-language UI — switch between EN, ES, FR, DE, PT with LANG command.
a
Lowercase + Accents — full a-z font support, dead-key accents ('+vowel = áéíóúñü).
M
System Monitor — real-time CPU task info, memory stats, and uptime display.
F
File Manager — browse, open, and delete files from the desktop.
U
User Accounts — multi-user login with USER, LOGIN, LOGOUT, UNLOCK.
C
User Commands — define custom shell commands with UCMD saved to disk.

v0.2 Changelog

Event-driven architectureISRs push events to lock-free queue; main loop pops and dispatches. No more UI calls from interrupt context.
Stack canary0xDEADC0DE guard words at both ends of every task stack, verified on task switch.
Keyboard ISR minímaIRQ33 only pushes raw scancode; decoding (shift, ctrl, accents) moved to kb_process().
FS directory cacheRoot directory cached in RAM (224 entries). DIR and file lookups scan memory, not disk.
FAT lazy syncfat_dirty flag avoids redundant disk writes when FAT hasn’t changed.
Z-order windowsSeparate z-order array decouples visual stacking from window array index.
HLT optimizationMain loop halts CPU when only idle task runs (no busy-wait in scheduler).
Password on diskSystem password read from PASS.SYS instead of hardcoded string.
Dynamic shell outputTerminal buffer expanded to 32×48; scrolls dynamically based on window height.
Dirty flagsDesktop, windows, system monitor, and file manager skip redraw when nothing changed.
Atomic mouse readscli/sti guards around mouse position reads in click/drag handlers.
Source reorganizationFiles organized into core/, drivers/, ui/, ml/, apps/ subdirectories.

Build from Source

Requires a cross-compiler (i686-linux-musl-gcc), NASM, Python 3, and Linux/WSL.

$ git clone <repo-url> kronos
$ cd kronos
$ bash build_full.sh

The script compiles the kernel, assembles the bootloader, and produces cortexos.img.
