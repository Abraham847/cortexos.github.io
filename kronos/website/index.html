Quick Start

QEMU (Linux / Windows / macOS)

$ qemu-system-i386 -drive file=cortexos.img -drive file=hdd.img -netdev user,id=net0 -device rtl8139,netdev=net0 -vga std -m 128 -audiodev sdl,id=audio0 -soundhw sb16

Minimal (no audio, no network):

$ qemu-system-i386 -drive file=cortexos.img -m 64
Tip: 128 MB RAM recommended for NN training. Network requires -netdev user -device rtl8139.

VirtualBox Setup

  1. Create a new VM: Type = Other, Version = Other/Unknown (32-bit).
  2. Set RAM to at least 32 MB (64 MB recommended).
  3. Storage: Add a floppy controller, attach cortexos.img or cortexos.vdi.
  4. Alternatively, attach the VDI as an IDE Primary Slave (set type to Floppy or IDE).
  5. In System → Motherboard, enable I/O APIC and Enable EFI (special OS only) if needed.
  6. Boot the VM.
Note: VirtualBox floppy mode lacks INT 13h extensions. The bootloader detects this automatically and falls back to CHS addressing — no configuration needed.

You can also convert the image yourself:

$ VBoxManage convertfromraw cortexos.img cortexos.vdi --format VDI

Real Hardware (Floppy / USB)

Write the image to a 1.44 MB floppy disk or USB drive:

Linux

$ dd if=cortexos.img of=/dev/sdX bs=512 conv=fsync

Windows

> Win32DiskImager.exe cortexos.img \\.\X:
Warning: Make sure to select the correct drive. All data on the target will be destroyed.

Features

N
Dual Neural Network Engine — Fixed-point (16.16) for compatibility and native float (FPU-accelerated) for precision. KPU (Kronos Processing Unit) enables hardware FPU matmul, sigmoid, ReLU. Create and train NNs via GUI Creator with Float/Fixed toggle.
T
TCP/IP Stack — Ethernet, ARP, IP, ICMP (ping), TCP (connect/send/recv/close), DNS resolution, DHCP client. RTL8139 NIC driver with PCI bus scan.
V
VESA Framebuffer — 1024×768 256-color mode with linear framebuffer mapping above 1MB. Window manager with taskbar, clock, and icon desktop.
A
SB16 Audio — Sound Blaster 16 DSP driver with DMA. SOUND PLAY freq ms and SOUND VOL commands.
U
User Apps — Flat binary format (.BIN) with checksum verification. Apps loaded at 0x50000, linked against kernel API. RUN app.BIN command.
S
Shell + Scripting — 35+ commands, command history, user-defined commands, FORTH interpreter, EXEC file.txt batch execution.
F
File Systems — FAT12/FAT32 auto-detect, procfs, devfs, tmpfs. Multi-disk support (ATA master/slave). File manager with size display.
I
AI Studio Suite — 5-panel IDE for data, model, training, inference, export. AI Lab launcher, AI Creator wizard with presets (XOR, AND, OR) and custom architectures. NN Viewer exports trained weights as CSV (S) — readable from Windows.
H
Hardware Support — PCI bus scan, RTC (CMOS clock), ATA PIO (master/slave), PS/2 keyboard + mouse, timer (100Hz). 192KB heap for datasets.
D
Desktop GUI — Window manager (drag, focus, close), 8-icon launcher, taskbar with clock, system monitor, file manager, text editor, paint app.

Build from Source

Requires i686 cross-compiler (e.g. i686-linux-musl-gcc), NASM, and Python 3. On Windows 10+, just run build.bat.

$ git clone https://github.com/Colibecas/kronos cortexos
$ cd cortexos
$ bash build_full.sh       # Linux / WSL
> build.bat                # Windows

The script compiles the kernel (~187KB), assembles the bootloader, and produces cortexos.img.
